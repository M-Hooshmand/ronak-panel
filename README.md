# روناک — پنل مدیریت (نمونه UI/UX)

نمونه تعاملی و لوکال پنل روناک: داشبورد یکپارچه‌سازی داده‌های مالی، پایش ایجنت‌ها،
کیفیت داده، اسناد حسابداری و ثبت سند در نرم‌افزار مقصد.
تمام داده‌ها نمونه و درون‌برنامه‌ای هستند؛ این پروژه بک‌اند و احراز هویت واقعی ندارد.

## اجرا

```bash
npm install
npm run dev -- --host 127.0.0.1 --port 5180
# http://127.0.0.1:5180
```

ساخت نسخه production و پیش‌نمایش:

```bash
npm run build
npm run preview      # http://127.0.0.1:4173
```

## stack

- React 18 + TypeScript + Vite 5
- react-router-dom برای مسیرها
- lucide-react برای آیکون‌ها
- CSS دست‌نویس با توکن‌های طراحی (بدون Tailwind/MUI)
- نمودارها: SVG دست‌ساز (`src/components/charts.tsx`)
- فونت وزیرمتن به‌صورت لوکال در `public/fonts`
- RTL کامل، اعداد فارسی، تم دارک فین‌تک

## صفحه‌ها

| مسیر | صفحه | محتوا |
|---|---|---|
| `/login` | ورود | ورود سازمانی، SSO، پنل برند |
| `/` | نمای مدیریتی | نقدینگی، چک‌ها، انبار، دارایی، سود و زیان، حقوق و مالیات، هشدارها |
| `/treasury` | خزانه‌داری | حساب‌ها، چک‌های دریافتی/پرداختی، وصول‌شده و سرسید |
| `/inventory` | انبار و دارایی | موجودی، حد سفارش، پیشنهاد خرید، دارایی ثابت و استهلاک |
| `/statements` | صورت‌های مالی | سود و زیان، ترازنامه، جریان نقد |
| `/payroll` | حقوق و مالیات | لیست حقوق، بیمه، مالیات حقوق، ارزش افزوده و تعهدات |
| `/dashboard` | داشبورد یکپارچه‌سازی | KPI پردازش، روند داده، وضعیت اسناد، جریان‌ها |
| `/sources` | منابع داده | جدول منابع SQL، افزودن منبع (چندمرحله‌ای + تست اتصال) |
| `/agents` | ایجنت‌ها | وضعیت ایجنت‌ها، ضربان قلب، توکن، جزئیات |
| `/pipelines` | جریان‌ها | مراحل استخراج→بارگذاری، اجرای جریان، تاریخچه |
| `/quality` | کیفیت داده | امتیاز، دسته مشکلات، قواعد، جدول موارد |
| `/vouchers` | اسناد حسابداری | فیلتر، جدول اسناد، جزئیات سند، نگاشت حساب، ثبت در مقصد |
| `/reports` | گزارش‌ها | نمودارهای فروش، تراز، وضعیت اسناد، عملکرد ایجنت |
| `/logs` | لاگ رویدادها | جدول لاگ با سطح رویداد و فیلتر |
| `/settings` | تنظیمات | عمومی، امنیت/TLS، نگاشت، اعلان، کاربران |

## ساختار

```
src/
  components/   Layout (سایدبار/تاپ‌بار)، Brand، charts، ui
  pages/        یک فایل برای هر صفحه
  lib/          داده‌های نمونه (data.ts) و قالب‌بندی فارسی (format.ts)
  styles/       tokens / base / layout / components / pages
```

## نکات برای جلسه

- سایدبار سمت راست و کل رابط RTL است؛ اعداد با `toLocaleString("fa-IR")` فارسی می‌شوند.
- در `/vouchers` روی یک ردیف کلیک کنید تا جزئیات سند و دکمه «ثبت سند در نرم‌افزار مقصد» باز شود.
- در `/sources` دکمه «افزودن منبع» یک ویزارد با تست اتصال شبیه‌سازی‌شده دارد.
- در `/pipelines` دکمه «اجرای جریان» وضعیت اجرا را انیمیت می‌کند.
- داده‌ها ثابت‌اند؛ برای اتصال واقعی، لایه `lib/data.ts` را با API جایگزین کنید.
